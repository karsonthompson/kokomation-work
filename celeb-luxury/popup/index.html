Before: current popup

There is no popup on the site today, and no signup form anywhere. A bar at the top of the site hands every visitor the code FIRSTORDER for 15% off, and asks for nothing in return.

The current setup: no popup, and the 15% code sitting in a banner for anyone to take.

After: new popup

Step 1 of 4: the scratch-off. 15% off stated up front, and the code sits under the foil.

Open the full popup

What it improves

  • The discount is given away. The banner code costs the visitor nothing, so the brand gets no email address and no way to follow up.
  • No way to join. There is no popup or signup form anywhere on the store, so the 15% is never traded for an email address.
  • Now the code is earned. The rebuild turns the same 15% into a mystery scratch-off: scratching reveals the discount, and the code itself only goes out by email once a visitor signs up.

The average popup signs up about 2 to 3 of every 100 visitors. A strong one gets 5 or more. On 10,000 visitors a month, that gap is 200 extra people in your welcome flow every single month, from traffic you already paid for. The welcome flow is where first orders come from, so those 200 people are the difference between email being a side channel and email being a revenue channel.
